# Link Share Forever

Share links with your friends with RSS: https://link-share.graic.net

Link Share Forever is a rewrite of [Link Share](https://github.com/Graicc/link-share/) focused on lasting forever.
It is written in C with minimal dependencies (SQLite, OpenSSL, curl, libc), and hosted on a free tier VM (from Oracle).

Example: [My feed](https://link-share.graic.net/view/Graic)
